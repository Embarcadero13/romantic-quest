# Romantic Quest — романтический 3D-квест

Интерактивный сайт из пяти глав (React + TypeScript + Vite + Three.js / React Three Fiber).
Сайт не использует серверы, базы данных и платные сервисы.

> Проект написан, но автоматически не запускался и не тестировался. Если при запуске появится ошибка — скопируйте её текст и отправьте Claude, он исправит.

## Где менять тексты

Файл **`src/data/story.ts`** — имена, комплименты, послания в саду, письмо, финальная надпись. Меняйте только текст внутри кавычек.

## 1. Скачать и распаковать (Windows)

1. Скачайте ZIP-архив из чата.
2. Нажмите на файл правой кнопкой мыши → **«Извлечь всё…»** → **«Извлечь»**.
3. Лучше переместить папку `romantic-quest` в простое место, например `C:\Projects\romantic-quest` (без русских букв в пути).

## 2. Установить Node.js

1. Откройте https://nodejs.org и скачайте версию **LTS**.
2. Установите, везде нажимая «Next».
3. Перезагрузите компьютер (или хотя бы закройте и заново откройте все окна).
4. Проверка: откройте PowerShell и введите `node -v` — должен появиться номер версии.

## 3. Открыть терминал в папке проекта

Откройте папку `romantic-quest` в Проводнике, нажмите в адресную строку, введите `powershell` и нажмите Enter.

## 4. Установить зависимости и запустить

```
npm install
npm run dev
```

Откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173/). Остановить сайт: `Ctrl + C` в терминале.

Проверка сборки: `npm run build`.

## 5. Опубликовать на GitHub Pages

1. Зарегистрируйтесь на https://github.com и нажмите **New repository**. Назовите, например, `romantic-quest`, выберите **Public**, нажмите **Create repository**.
2. Установите Git: https://git-scm.com/download/win
3. В терминале в папке проекта введите (замените `USERNAME` и `REPOSITORY` на свои):

```
git init
git add .
git commit -m "Первая версия"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

4. На GitHub откройте репозиторий → **Settings** → **Pages** → в разделе **Source** выберите **GitHub Actions**.
5. Откройте вкладку **Actions** и дождитесь зелёной галочки (1–3 минуты).
6. Сайт будет по адресу `https://USERNAME.github.io/REPOSITORY/`.

Настройка адреса не нужна: в `vite.config.ts` используется `base: './'`.

## 6. Обновить сайт после изменений

```
git add .
git commit -m "Обновил тексты"
git push
```

Через пару минут сайт обновится сам.

## Необязательно: музыка и фото

- Музыка: положите файл `music.mp3` в папку `public/`. Тогда в правом верхнем углу появится кнопка ♪. Без файла сайт работает, кнопки нет. Используйте музыку, на которую у вас есть права.
- Фото в проекте не нужны: все сцены — 3D.

## Слабое устройство

Кнопка **«Лёгкий режим»** вверху уменьшает число частиц и качество картинки. Он включается автоматически на слабых устройствах.

## Структура

```
src/data/story.ts      все тексты
src/App.tsx            главы, интерфейс, письмо
src/scenes/World.tsx   3D: сердце, сад, сердца-комплименты, конверт, звёзды, лепестки
src/styles.css         оформление
.github/workflows/     публикация на GitHub Pages
```
